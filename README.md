# ДЖАПМЕРЫ

Платформер на HTML / CSS / Vanilla JS (Canvas, ES-модули).

## Управление

* **Клавиатура:** ← → / A D — ходьба, Space / W — прыжок
* **Телефон:** экранные кнопки ◀ ▶ ▲ (удержание)

## Цель

Выберать одного из трёх джамперов, соберать **5 червяков** и дойти до финиша.  
Не касайться препятствий (let). Рекорд — лучшее время.


## Структура

```
index.html
style.css
main.js          — загрузка ассетов, старт
Game.js          — игровой цикл, уровень, UI, выбор персонажа
Player.js        — персонаж, физика, анимация состояний
input.js         — клавиатура и тач
collision.js     — AABB и платформы
assets/          — спрайты
README.md
```

## Особенности

- Выбор персонажа в начале («выбери своего джампера»): pten1, pten2, pten3
- Состояния спрайтов: idle, открытый рот (_1), прыжок, прыжок с открытым ртом
- Препятствия `let` — можно перепрыгнуть, касание = поражение
- 5 червяков, счёт, таймер, рекорд в localStorage
- Старт / пауза / рестарт, мобильные кнопки

## Нейросеть и промпты
